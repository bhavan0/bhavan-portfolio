## Key Insights & Learnings 💡

### Technical Insights

1. **Component Simplicity**
   - HeroSection is a single, focused component (~50 lines)
   - No complex state management needed
   - Theme support via Tailwind `dark:` variants is clean and maintainable

2. **Button Styling Pattern Established**
   - Primary CTA: `bg-black dark:bg-white text-white dark:text-black`
   - Secondary CTA: `border-2 border-black dark:border-white`
   - This pattern is reusable across the application

3. **Download Attribute Best Practice**
   ```html
   <a href="/assets/resume.pdf" download="bhavan-resume.pdf">
   ```
   - Forces browser download instead of navigation
   - Sets consistent filename regardless of source file name
   - Works on same-origin URLs

4. **Service Injection Pattern**
   - `@inject IScrollService ScrollService` at component level
   - Clean separation between component and service
   - Enables testability (can mock IScrollService)

### Process Insights

1. **Small Epics Ship Fast**
   - 3 stories completed in single session
   - Less context switching than larger epics
   - Each story builds directly on the previous

2. **Review Fixes Are Valuable**
   - Accessibility attributes caught in review
   - Touch target guarantees added via review
   - Pattern: implement fast, catch issues in review

3. **Placeholder Strategy Works**
   - Code infrastructure complete even without final content
   - Resume.pdf.placeholder documents requirements
   - Enables parallel content creation
